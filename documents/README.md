# `documents/` — Personal Documents

User's personal document storage used by the resume parser and profile generator.

```
documents/
├── certificates/        # Certificates (PDF/images)
├── internship_letters/  # Internship offer/completion letters
├── marksheets/          # Academic marksheets
├── offer_letters/       # Job offer letters
└── photo/               # Profile photo
```

Referenced by `core/resume_parser.py` when parsing resumes and extracting structured data.
